# v0.1.5 Lite · 可选精简版

[默认推荐完整版](https://github.com/3289192-bot/dsh-cache-bricks/releases/tag/v0.1.5)。Lite 下载放在同一发布页下方。

- 优化落砖与整列平移动画，减少布局开销。
- 修复系统开启“减少动态效果”时落砖动画消失的问题。
- 修复虚线落砖位置与棋盘移动不同步。
- 保留缓存读数、颜色提示、滑条回看与旧会话补载。

[下载 Lite v0.1.5](https://github.com/3289192-bot/dsh-cache-bricks/releases/download/v0.1.5/lite-dsh-cache-bricks-0.1.5.tgz)

```sh
dsh plugin --profile web add github:3289192-bot/dsh-cache-bricks#v0.1.5-lite
```

当前公开验证基线为 DSH `0.1.7-rc.2` Web profile。其他版本未经本次兼容性测试，不保证兼容，不限定只能安装在 rc.2。历史开发验收记录另见 `docs/release-history.md`。
