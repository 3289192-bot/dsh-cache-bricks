## 兼容性

当前公开验证基线为 **DSH `0.1.7-rc.2` Web profile**。其他版本未经本次兼容性测试，不保证兼容，不限定只能安装在 rc.2。

历史开发记录确实还包含 `0.1.6-alpha.1` 的本地装机使用结果，保留这个事实；它不表示本次发布已经完整验证该版本或其他 DSH 版本。

DSH 客户端 peer 声明放宽并标记 optional；开发依赖仍固定到 rc.2。插件仍依赖宿主提供相应模块和服务，放宽安装声明不等于 API 一定兼容。

## 已有验收与本次整理

本地冻结记录报告 typecheck、95 项单测、host 构建检查及 49 项浏览器 fixture 检查通过；本次发布没有重跑测试或新增真实模型调用。发布核对源码、构建文件与冻结版本的一致性，检查包内文件与下载内容。

历史性能表及旧版本说明以当时构建为准。用户提供的完整版使用说明图放在 main；其中详情弹窗、类型翻面、定位和对比不属于 Lite。
