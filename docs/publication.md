## 兼容性表述

当前公开测试使用基线为 **DeepSeek Harness `0.1.7-rc.2` Web profile**。其他版本没有完成本次兼容性测试，不保证兼容；不再限定只能安装在 rc.2。

DSH 客户端的 `peerDependencies` 使用非锁定声明，并标为 optional，避免为插件额外安装另一套宿主客户端包。`devDependencies` 与开发锁文件仍固定到 rc.2，用于复现本次构建基线。宿主仍必须提供插件所需的客户端模块和服务；宽松安装声明不保证 API 兼容。
