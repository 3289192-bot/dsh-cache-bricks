## 冻结时包含什么

- **宿主半边**（三个 tap）：`llm/stream` 只计数并原样返回模型流；`agent/assistant-stream` 取身份
  （`turn`/`step`/`attemptId`），`usage` chunk 当占位，**其余 delta 连读都不读**；`session/event` 的
  settlement 才落砖。砖 = 11 个字段，环形缓冲 1024 块/会话，满了丢最老的并报数。
- **旧会话 backfill**：有人看某个会话时，**读一次**它自己的日志（只取 settlement 与 `turn/end`），
  按同样 11 个字段填进同一个环；正在跑的那一步以实时为准；`backfill: false` 可关。
- **棋盘**：0.1.3 的美术与动画整套（安静 18% 绿、`#dc2626` 红、灰、`inset` 高光、12px tabular 数字、
  420ms 落砖曲线、260ms 左移、悬停提亮、`prefers-reduced-motion` 全关），加上**两把滑条**（拖拽/点轨/
  滚轮只在滑条上/双击回顶/方向键 Home End/暗角/`⤓ 最新`）、地板线、正在跑的那一轮的虚线落砖格。
- **HTTP**：`/cache-bricks/sessions`、`/bricks`、`/stream`（SSE）；`/blob` 不存在，因为什么都不存。

## 冻结时明确不含什么

prompt / 消息 / system prompt、工具调用与 schema、request 信封与 header、stream 与时间线、TTFT/TPS、
retry 元数据（除 attempt 序号）、diff、导航与定位、Inspector、类型背面与翻转、catalog/索引/回放、
任何落盘。完整清单与理由见 [cache-brick-contract.md](cache-brick-contract.md)。
